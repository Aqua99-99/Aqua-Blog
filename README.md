# 황준현 블로그

공부 기록과 포트폴리오를 담는 사이트입니다. 포트폴리오는 노션에 적으면 자동으로 올라가고, 글은 이 저장소의 마크다운 파일로 씁니다.

- 주소: https://aqua99-99.github.io/Aqua-Blog/
- 만든 도구: Astro, GitHub Pages, 노션 API

## 포트폴리오 항목 올리기

1. 노션의 `포트폴리오` 데이터베이스에 항목을 만들거나 고칩니다.
2. `공개`를 체크합니다. 체크하지 않은 항목은 사이트에 나오지 않습니다.
3. 다음 날 아침 6시쯤 자동으로 반영됩니다. 바로 올리려면 GitHub 저장소의 **Actions** 탭 → **사이트 배포** → **Run workflow**를 누릅니다.

내리고 싶으면 `공개` 체크를 풀면 됩니다. 반영 시점은 올릴 때와 같습니다.

### 속성

| 속성 | 꼭 필요 | 설명 |
|---|---|---|
| 이름 | 예 | 자격증이나 활동의 이름 |
| 구분 | 예 | `자격증`, `수료`, `수상`, `대외활동` 중 하나 |
| 기관 | | 발급·주관 기관 |
| 날짜 | | 취득일 또는 활동 기간. 비우면 목록 맨 뒤로 갑니다 |
| 요약 | | 목록에 보이는 한두 문장 |
| 증빙 | | 수료증 이미지나 PDF. 생년월일, 수험번호 같은 개인정보를 가린 파일만 올리세요 |
| 대표 | | 체크하면 홈 화면에 나옵니다 (자격증·수료·수상 최대 4개, 대외활동 최대 3개) |
| 공개 | | 체크한 항목만 사이트에 나옵니다 |
| 슬러그 | | 상세 페이지 주소에 쓸 영문 이름(소문자, 숫자, 하이픈). 비우면 자동으로 정해집니다 |

항목 페이지에 본문을 쓰면 그 항목의 상세 페이지가 생깁니다. `구분`이 `대외활동`인 항목에서 `자세히 보기`로 연결됩니다.

### 본문에 쓸 수 있는 블록

문단, 제목 1~3, 글머리 기호 목록, 번호 목록, 인용, 코드, 이미지, 파일, PDF, 구분선, 그리고 굵게·기울임·인라인 코드·링크.

토글, 표, 콜아웃, 하위 페이지 같은 다른 블록은 사이트에 나오지 않고 건너뜁니다. 건너뛴 블록은 Actions 로그에 `지원하지 않는 블록을 건너뜁니다`로 남습니다.

## 글 쓰기

`src/content/posts/` 에 마크다운 파일을 만들고 `main`에 올리면 게시됩니다.

```markdown
---
title: "글 제목"
description: "목록과 검색 결과에 보이는 한 줄 설명"
date: 2026-11-12T10:00:00+09:00
tags: ["AWS", "보안"]
draft: false
---

본문
```

파일 이름이 주소가 됩니다. `kms-envelope-encryption.md` 는 `/posts/kms-envelope-encryption/` 로 올라갑니다.

## 처음 한 번 하는 설정

1. **노션 연동 만들기**: https://www.notion.so/profile/integrations 에서 새 내부 연동을 만들고, 권한은 "콘텐츠 읽기"만 켭니다. 발급된 토큰을 복사합니다.
2. **데이터베이스에 연결**: 노션에서 `포트폴리오` 데이터베이스를 열고 오른쪽 위 `···` → `연결` 에서 방금 만든 연동을 추가합니다.
3. **저장소 비밀값**: GitHub 저장소 **Settings → Secrets and variables → Actions** 에 두 개를 넣습니다.
   - `NOTION_TOKEN`: 1번에서 복사한 토큰
   - `NOTION_DATA_SOURCE_ID`: `포트폴리오` 데이터베이스의 data source ID
4. **Pages 켜기**: **Settings → Pages → Source** 를 `GitHub Actions` 로 바꿉니다.

토큰은 저장소 파일이나 글에 적지 마세요.

## 내 컴퓨터에서 보기

Node 22.23 이상이 필요합니다.

```bash
npm install
PORTFOLIO_FIXTURES=1 npm run dev   # 노션 대신 예시 항목으로 화면을 띄웁니다
npm test                           # 시험
```

실제 노션 내용으로 보려면 `NOTION_TOKEN`, `NOTION_DATA_SOURCE_ID` 를 환경 변수로 주고 `npm run dev` 를 실행합니다.

## 배포가 실패했을 때

Actions 탭에서 실패한 실행을 열고 "사이트 빌드" 단계의 마지막 줄을 봅니다. 실패하면 사이트는 직전 상태로 남아 있습니다.

| 메시지 | 뜻 | 고치는 법 |
|---|---|---|
| `환경 변수 NOTION_TOKEN 이 없습니다` | 비밀값이 저장소에 없음 | 위 3번 |
| `API token is invalid` | 토큰이 틀렸거나 폐기됨 | 토큰을 다시 발급해 3번 |
| `object_not_found` 또는 `Could not find` | 연동이 데이터베이스에 연결되지 않았거나 ID가 틀림 | 위 2번, 3번 |
| `"구분"이 비어 있습니다`, `"이름"이 비어 있습니다` | 공개한 항목에 꼭 필요한 값이 없음 | 메시지에 나온 항목을 노션에서 채움 |
| `슬러그 "..." 가 겹칩니다` | 두 항목의 슬러그가 같음 | 한쪽을 바꿈 |
| `파일을 내려받지 못했습니다` | 노션 파일을 받지 못함 | 다시 실행. 계속되면 그 파일을 노션에 다시 올림 |

클라우드에 관심이 많아서 혼자 공부하고 있다. 배운 걸 머릿속에만 두면 금방 흐려지니, 공부한 과정을 이 블로그에 남기기로 했다.

## 왜 블로그부터 클라우드에 올릴까

AWS 서비스 이름과 개념은 자격증 공부로 어느 정도 알고 있다. 이제는 개념으로 아는 것을 직접 만들어 보고 싶다. 가장 가까운 연습 대상이 바로 이 블로그다.

계획한 구성은 이렇다.

```text
글 작성 (Markdown)
  → GitHub
  → GitHub Actions (빌드)
  → S3
  → CloudFront
  → 방문자
```

## 앞으로 쓸 글

- 이 블로그를 S3와 CloudFront에 올리는 과정
- 도메인 연결과 HTTPS 적용
- GitHub Actions로 자동 배포하기
- 홈랩에서 나만의 클라우드를 구축하고 운영하기

> 완벽한 글보다 꾸준한 기록을 목표로 한다.

막힌 곳과 해결한 방법을 그대로 적어 두려고 한다.
